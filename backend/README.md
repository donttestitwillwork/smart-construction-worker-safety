# 🖥️ Backend

The backend provides the communication layer between the smart helmet,
database, and monitoring dashboard.

It is built with **Node.js** and provides the server-side functionality
required by the Smart Construction Worker Safety Monitoring System.

## 🛠️ Technologies

- Node.js
- Express.js
- MySQL
- JavaScript
